Projects

  • Cross-Industry Privacy-Preserving Framework for Predictive Maintenance (IDA 2024 Challenge)

    A federated, differentially private framework for RUL prediction on the SCANIA-X dataset. Combines numerical and categorical features into transformer embeddings with a TabTransformer, applies Spectral-DP and DP-SGD, and aggregates a global model across heterogeneous clients with the flwr library.

    • Best RUL prediction model on the dataset with an MSE of 2725 while preserving training-data privacy.
    • Built an advanced membership inference attack (white-box, gray-box, black-box plus time-series features) achieving 49.12% AUC and 49.59% accuracy, confirming strong privacy.
  • SENTRAL - Multi Spectrum Stock Analysis using custom LLMs

    A multi-spectrum stock analysis system combining fundamental analysis (14 metrics plus Piotroski F-Score and Altman Z-Score), technical analysis (18 indicators), news sentiment from 10 LLMs, and Transformer/LSTM forecasting to compute buy/hold/sell probabilities.

    • Collected news via seven APIs plus web scraping and filtered items by relevance before LLM sentiment extraction.
    • Ensembled sentiment with fundamental and technical indicators, boosting a newbie portfolio by +45% over five months.
  • Context-Aware Multimodal Knowledge Retrieval System

    A retrieval system that parses and separately processes multimodal content (images, tables, equations, graphs, text), summarises each modality into embeddings stored in ChromaDB, and answers queries with source-cited, multimodal responses.

    • Employed modality-specific pipelines with the most appropriate LLM per content type.
    • Designed a multi-vector retrieval strategy linking summaries to original content for context preservation.
